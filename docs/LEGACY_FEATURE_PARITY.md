# 🧭 DashTiny — Legacy Feature Parity Map

> **Reference Repository**: [`jagga2105/dashtiny_mvp_angular`](https://github.com/jagga2105/dashtiny_mvp_angular)  
> **Current Repository**: [`jagga2105/dashtiny-web`](https://github.com/jagga2105/dashtiny-web)  
> **Engineering Principle**: *"AI proposes. Tools verify. Services execute. The database remembers. The UI lets the traveler decide."*

---

## 1. Classification Guidelines

Every feature from the legacy Angular MVP is classified into one of five categories:
- **`KEEP BEHAVIOR`**: The user-facing workflow, UX intent, or domain capability is valuable and should be preserved in the modern app.
- **`REBUILD DOMAIN`**: The core domain logic, normalization schema, and backend models must be reconstructed on FastAPI + SQLAlchemy + PostgreSQL.
- **`REBUILD UI`**: The user interface must be redesigned from scratch using Next.js 15, TailwindCSS, Lucide icons, and the DashTiny warm-editorial aesthetic.
- **`REPLACE IMPLEMENTATION`**: The architectural mechanism (e.g., RxJS, Angular Dialogs, html2pdf.js, local SQLite) must be substituted with modern Next.js / FastAPI equivalents.
- **`DISCARD`**: The feature is an architectural anti-pattern, dead code, e-commerce template placeholder, insecure credential leak, or outside the Trip-centric MVP scope.

## 3. Discard & Do-Not-Port Manifest

The following elements from `dashtiny_mvp_angular` are **strictly prohibited** from being ported into `dashtiny-web`:

1. **Angular 16 Framework & Dependencies**:
   - `@angular/*`, `zone.js`, `tslib`, Angular modules, `@agm/core`, `@angular/google-maps`.
2. **Reactive Extensions**:
   - `rxjs`, `BehaviorSubject`, `Observable`, `Subscription` memory leaks.
3. **Styling & Layout Frameworks**:
   - Angular Material (`@angular/material`, `@angular/cdk`), Bootstrap 5 (`bootstrap`, `@ng-bootstrap/ng-bootstrap`, `ngx-bootstrap`, `popper.js`), jQuery.
4. **Legacy Backend Stack**:
   - `server.js` (Express + deprecated OpenAI `davinci`), `db.js` (Express + Mongoose + local MongoDB).
5. **Runtime SQLite Files**:
   - Do NOT run SQLite queries against `airports.db` or `flights.db` inside Next.js or FastAPI runtime.
6. **Hardcoded Credentials & Client Keys**:
   - MapTiler API keys (`fkeliYVYNI0EGeqQy1HE`), RapidAPI keys, Gemini browser keys, Unsplash access tokens.
7. **Direct DOM Mutation**:
   - `document.body.innerHTML = printContent` hacks.
8. **E-Commerce Placeholder Code**:
   - Shirt product catalogs in `hotel-cards.component.html`.
9. **Direct Unchecked AI Mutation**:
   - Free-form JSON injection directly into client UI without proposal review.
